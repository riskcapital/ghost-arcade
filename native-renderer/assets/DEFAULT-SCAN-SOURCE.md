# default-scan.ply

The point cloud the cloud instruments draw when no scan is picked.

- Source: "Marble Bust 01" by Rico Cilliers, Poly Haven
  https://polyhaven.com/a/marble_bust_01
- Licence: CC0 1.0 (public domain), https://polyhaven.com/license
  Usable in a commercial app; no attribution required.
- Made from the 2K glTF (mesh + 2K diffuse texture): 170,000 points sampled
  uniformly over the surface by area, each coloured from the diffuse texture
  at its UV; centred, Y up; binary little-endian PLY (float xyz, uchar rgb),
  2.5 MB.
