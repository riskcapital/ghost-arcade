# Pro test fixtures

The main `.gha` file generated by `tools/generate-test-project.mjs` that
exercises every Pro-only feature added in v0.3.9 (dual-deck VJ,
crossfader, macros, snapshots). Use it as a smoke test on each platform
before shipping.

## Files

| File | Purpose |
|---|---|
| `Test_Full_Pro_v1.gha` | The main test project. Loads everything. ~240 KB. |

## How to run the smoke test

1. Launch Ghost Arcade (Pro build).
2. **File → Open Project…** → select `Test_Full_Pro_v1.gha`.
3. Walk through the checklist below.

## Checklist (what to confirm)

### Project + layers
- [ ] 4 layers visible: `L0 · Backdrop`, `L1 · Pulse`, `L2 · Kaleido`, `L3 · Accent`
- [ ] Project is 1920×1080
- [ ] Layer L1 is selected on load
- [ ] Each layer has a working shader preview (solid colour / radial pulse / kaleidoscope / tunnel)

### VJ Clip Launcher (dual-deck)
- [ ] Open VJ panel — see 4 layers × 8 columns clip grid
- [ ] **Bank A** clips are labelled `A1 · Pulse Slow` … `A8 · Solid Cyan`
- [ ] **Bank B** clips are labelled `B1 · Pulse Fast` … `B8 · Solid Lime`
- [ ] Switch between Bank A / Bank B view → grid contents change
- [ ] Two blocks: `Main` (active) + `Breakdown` — switching blocks swaps both grids
- [ ] Layer 0 has `A1 · Pulse Slow` LIVE on Bank A (column 2 lit)
- [ ] Bank B layer 0 has `B1 · Pulse Fast` LIVE (column 0 lit)
- [ ] Bank A layer 3 is muted; Bank B layer 3 is soloed
- [ ] **Master opacity = 0.85** in the header

### Crossfader
- [ ] Crossfader is enabled and sits at 0.5 (centre)
- [ ] Transition = `dissolve`, blend mode = `normal`
- [ ] Drag crossfader 0 → 1 → smoothly fades from Bank A live to Bank B live output
- [ ] Try changing transition (`cut`, `wipeleft`, etc.) — visible behaviour changes
- [ ] Try changing blend mode (`multiply`, `screen`, `add`) — composite output blends with the alternate deck differently

### Quantization
- [ ] Quant grid shows `1bar`
- [ ] Trigger a clip on a non-active column — clip launches on the next bar boundary (with default 120 BPM, this is ~2s after click)
- [ ] Switch to `off` — clips trigger immediately
- [ ] Switch to `1/4` — clips snap to the next beat

### Macros (8 knobs across the top)
- [ ] All 8 knobs visible: `ENERGY`, `CHAOS`, `DRAMA`, `BUILD`, `SUB`, `AIR`, `FX`, `WILD` with distinct colours
- [ ] Right-click any knob → **Edit Macro** popover opens with `+ Add Effect` button (same picker as layer effects)
- [ ] Add an effect to a macro and turn the knob — effect ramps from dry → wet on the composite output
- [ ] **`BUILD`** is auto-pulsing on `2bar` with `saw-up` shape — its knob ramps 0 → 1 over 2 bars and snaps back
- [ ] **`SUB`** is auto-pulsing on `1/4` with `square` shape — its knob strobes on the beat (0 ↔ 0.6)
- [ ] Effects can be drag-reordered, toggled (●/○), and per-effect opacity tuned in the popover

### Snapshots (16-slot bank, 4 populated)
- [ ] Slots 1, 2, 5, 9 show coloured/named badges; slots 3, 4, 6–8, 10–16 are empty
- [ ] **Recall slot 1 (`Open · Soft A`)**: master drops to 0.6, crossfader → 0, Bank B layers go silent
- [ ] **Recall slot 2 (`Build · Mix 50`)**: crossfader → 0.5, master → 0.85, both decks active at half opacity
- [ ] **Recall slot 5 (`Drop · Hard B`)**: crossfader hard-cuts to 1.0 (transition switches to `cut`), Bank A muted, Bank B full, selectedDeck → B
- [ ] **Recall slot 9 (`Breakdown · Solo L3`)**: only Layer 3 visible, transition = `wipeleft`, master = 0.4
- [ ] Save a new snapshot to slot 3 — comes back from disk preserved on next reload
- [ ] Clear slot 5 — slot reverts to empty placeholder

### Compositions
- [ ] Two compositions: `Festival Main` (active) + `Intimate Set`
- [ ] Switching compositions changes the per-layer opacities

### Stage preset
- [ ] One stage preset saved: `Main Wall + Side Cubes` — load it and confirm layer positioning matches saved corners

## Regenerating

If the .gha format bumps or you want a different fixture, edit
`tools/generate-test-project.mjs` and re-run:

```bash
node tools/generate-test-project.mjs
```

The script is deterministic (UUIDs are sha1-derived from a counter), so
re-running with no source changes produces an identical-byte file. Diffs
in the committed `.gha` reflect intentional changes to the fixture spec.
