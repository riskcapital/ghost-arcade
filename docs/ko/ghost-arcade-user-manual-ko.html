1. 문서 범위와 번역 원칙

이 설명서는 Ghost Arcade 1.9.993의 현재 공개 소스와 한국어 UI catalog를 기준으로 작성했습니다. 앱에서 선택 가능한 내장 UI는 영어와 한국어이며, 한국어가 누락된 catalog key는 영어로 fallback됩니다.

영문이 정상인 항목
사용자가 입력한 프로젝트·레이어·프리셋 이름, 외부 플러그인·카메라·오디오 장치·OS가 제공하는 이름, API/코덱/제품명, MIDI·OSC 경로, IPC/protocol 값, GPU·FOV·NDI·A/B·X/Y/Z와 같은 기술 표기는 번역하지 않거나 업계 표기를 유지합니다.

2. 설치·실행과 한국어 전환

2.1 설치된 데스크톱 앱

  1. Windows 시작 메뉴 또는 바탕 화면에서 Ghost Arcade를 실행합니다.
  2. 프로젝터를 사용할 경우 OS 디스플레이 설정에서 복제가 아니라 확장을 선택합니다.
  3. 앱 우측 상단의 설정을 엽니다.
  4. 앱 → 언어 → 인터페이스 언어에서 한국어를 선택합니다. 즉시 반영되고 다음 실행에도 유지됩니다.

2.2 소스에서 실행

5. 미디어 가져오기와 레이어 구성

5.1 지원 source

이미지, 영상, ISF shader(.fs/.isf), HTML, JS/p5/Three.js animation, 화면·창 capture, webcam, NDI, Windows texture-share(Spout), PLY·Splat point cloud, GLTF/GLB/OBJ/FBX 3D model을 사용할 수 있습니다.

5.2 미디어 라이브러리

  1. 파일 추가로 source를 선택합니다.
  2. 항목을 클릭해 선택합니다. Ctrl/⌘은 다중 선택, Shift는 범위 선택입니다.
  3. 선택한 미디어 레이어에 적용하거나 VJ deck으로 drag합니다.
  4. Webcam/Capture/texture-share/NDI는 소스 탭에서 연결하고 live card의 추가 또는 정지 control을 사용합니다.

6. 매핑·워프·마스크·이펙트

6.1 transform과 content fit

선택 레이어의 position, scale, rotation, horizontal/vertical flip, opacity, blend mode를 설정합니다. 미디어는 Stretch/Fill/Crop 등 content fit을 선택하고 source crop을 별도로 조정할 수 있습니다.

6.2 코너와 메시 워프

  1. 레이어의 워프 영역에서 코너 또는 메시를 선택합니다.
  2. 코너 control point를 물리 표면의 네 꼭짓점에 맞춥니다.
  3. 곡면은 2×2~12×12 mesh grid를 선택하고 point를 조정합니다.
  4. 문제가 생기면 해당 layer warp의 초기화를 사용합니다.

6.3 mask·shape·edge feather

  • polygon mask: point 추가, invert, feather, shape별 edit/delete
  • shape: rectangle, circle, ellipse, triangle, polygon, custom path 등
  • edge feather: top/bottom/left/right를 독립 조정

6.4 이펙트 chain

  1. 레이어 이펙트의 추가를 눌러 catalog를 엽니다.
  2. effect enable/disable, expand, reset, remove, drag reorder를 사용합니다.
  3. 각 effect의 opacity, blend, preset, parameter를 조정합니다.
  4. parameter의 modulation control에서 audio band, amplitude, beat phase, LFO 등을 연결할 수 있습니다.

7. 화면·프로젝터·출력 보정

7.1 화면 구성

  1. 화면 탭에서 화면을 추가하거나 2-wide, 3-wide, 2×2 quick preset을 사용합니다.
  2. Master Canvas 해상도를 정합니다. 출력 장치의 실제 pixel topology와 맞추십시오.
  3. 각 화면의 slice rectangle을 canvas preview에서 배치합니다.
  4. 필요하면 rotation 0/90/180/270을 지정합니다.

7.2 물리 display 선택

  1. OS display 설정에서 projector를 확장 모드로 연결합니다.
  2. Screen Inspector에서 물리 디스플레이를 선택합니다.
  3. 목록이 오래되었으면 새로 고침을 누릅니다.
  4. 디스플레이에서 열기를 누릅니다. 주 모니터 선택 시 경고를 확인하십시오.
  5. output window를 닫으려면 inspector의 닫기 또는 output 창에서 Esc를 사용합니다.

8. VJ 모드와 A/B 크로스페이더

8.1 clip grid

  1. 상단 VJ를 엽니다.
  2. 미디어·shader·preset을 grid cell로 drag하거나 선택 후 deck에 추가합니다.
  3. cell click으로 trigger합니다. 우클릭으로 미리보기, 복사, 붙여넣기, 지우기를 사용합니다.
  4. column trigger는 같은 column의 clip을 함께 실행합니다.
  5. layer별 Solo, Mute, Stop, opacity, blend, effects를 설정합니다.

8.2 MIX·STAGE·MAP

  • MIX: VJ 합성 output을 전면 출력
  • STAGE: VJ layer를 mapping의 Screen layer로 routing
  • MAP: mapping view와 관련 control

8.3 Quantize와 panic

OFF, 1/4, 1/2, 1 bar, 2 bar, 4 bar 중 trigger timing을 선택합니다. 대기 중인 cell을 다시 누르면 취소됩니다. 긴급 시 모두 정지를 눌러 두 deck과 queue를 정리합니다.

8.4 A/B 크로스페이더

  1. A/B Crossfader를 켜면 두 독립 deck이 표시됩니다.
  2. Cut A/Cut B 또는 fader로 전환합니다.
  3. fade duration 0~8초, transition(dissolve, wipe, rgb-split, cube, shatter, halftone, glitch, liquid, strobe, slide), blend mode를 선택합니다.
  4. block은 클릭 선택, double-click rename, 우클릭 메뉴로 저장·복제·삭제합니다.

8.5 추가 공연 도구

Macro, Snapshot, Layer Sequencer, Composition/Layer/Clip/Stage effect, Performer(SynthVision), Stage3D를 같은 VJ workspace에서 사용할 수 있습니다.

9. 오디오·MIDI·OSC 연동

9.1 오디오

  1. toolbar의 audio picker에서 microphone 또는 system audio를 선택합니다.
  2. FFT bar를 눌러 sensitivity, smoothing, 8-band gain을 조정합니다.
  3. TAP으로 BPM을 입력하거나 자동 감지를 사용합니다.
  4. effect/layer parameter의 modulation에서 band, amplitude, beat, LFO를 연결합니다.
Electron Desktop의 system audio는 기본 화면의 loopback capture를 사용합니다. Browser의 화면 공유 절차와 다릅니다. macOS에서 Screen Recording 권한을 처음 허용한 뒤에는 앱을 완전히 종료하고 다시 실행해야 할 수 있습니다.

9.2 MIDI Learn

  1. 설정 → 연동 → MIDI에서 장치를 선택합니다.
  2. MIDI Learn 시작을 누릅니다.
  3. 앱 control을 클릭한 뒤 controller의 knob/fader/pad를 움직입니다.
  4. Esc로 Learn mode를 끝냅니다.

MIDI path(map:, vj:, vj-b:, sv:)는 저장·routing 식별자이므로 한국어 UI에서도 원문을 유지합니다.

9.3 OSC

설정 → 연동 → OSC에서 listener와 UDP port(기본 8000)를 설정합니다. binding의 address, target path, mode, min/max, invert를 지정하거나 Learn을 사용합니다.

OSC listener는 network interface에 열리며 별도 인증을 제공하지 않습니다. 신뢰할 수 있는 LAN과 firewall 안에서만 켜고 인터넷에 port forwarding하지 마십시오.
MIDI Clock 입력이 활성화되면 Ableton Link보다 우선할 수 있습니다. 공연 중 clock source를 하나로 정리하십시오.

10. 모바일 원격 제어

  1. 데스크톱 앱을 실행합니다.
  2. toolbar의 모바일 연결을 누릅니다.
  3. 휴대전화와 데스크톱을 동일한 신뢰할 수 있는 Wi-Fi에 연결합니다.
  4. QR code를 camera로 scan합니다. 기본 control WebSocket은 ws://호스트:9001, mobile page는 built-in HTTP server를 사용합니다.
  5. 연결 후 Mapping/VJ/Vision(native)/Paint mode를 선택합니다.

10.1 Mapping 원격

layer 선택, corner/mesh warp, opacity/blend/visibility, source·shape·effects, freeze/resume를 control합니다. touch drag와 two-finger zoom/pan을 지원합니다.

10.2 VJ 원격

clip/column trigger, block/bank, mixer, tempo·quantize, A/B crossfader·cut·transition, macro, snapshot, shader/effects, Stop All을 control합니다.

10.3 연결 복구

첫 연결은 6초 timeout을 사용합니다. 기존 연결이 끊기면 backoff로 재연결합니다. 연결 화면에서 URL을 확인하고 desktop firewall과 같은-LAN 상태를 점검하십시오.

보안: 모바일 제어 server를 공용 인터넷이나 신뢰할 수 없는 LAN에 노출하지 마십시오. 공연용 private router/hotspot 사용을 권장합니다.

11. 실시간 녹화·오프라인 렌더·변환

11.1 실시간 녹화

  1. 설정 → 녹화에서 format, bitrate(2.5/5/8/12 Mbps), 자동 다운로드와 저장 폴더를 정합니다.
  2. audio source가 활성이고 audio 포함 설정이 켜져 있으면 영상과 함께 기록합니다.
  3. toolbar ● 녹화를 누르고, 끝날 때 녹화 중지를 누릅니다.
  4. 결과는 미디어 라이브러리에 추가되고 설정에 따라 지정 폴더 또는 다운로드로 저장됩니다.
실시간 Record와 Screenshot은 editor의 raw/hidden canvas source를 우선 사용하므로 최종 WebGPU present, Master Warp, Dome 또는 output overlay와 화면이 다를 수 있습니다. 공연 전 짧은 test 녹화를 확인하십시오. Screenshot library 항목은 blob 기반이므로 project 재실행 후 유지되지 않을 수 있어 저장된 PNG 원본을 보관해야 합니다.

11.2 오프라인 비디오 렌더

  1. 파일 → 비디오로 렌더링...
  2. 이름, duration(0.5~3600초), FPS(24/30/60), resolution preset 또는 custom 값을 선택합니다.
  3. MP4 또는 JPEG sequence와 Web/High/Archive quality를 선택합니다.
  4. 시작 후 frame render → FFmpeg encoding → save 단계가 끝날 때까지 기다립니다.
오프라인 MP4 렌더는 project engine composite를 deterministic seek하여 생성하며 audio, Blackout/output overlay, 최종 WebGPU present와 per-output slice를 포함하지 않습니다. 실시간 audio 포함 결과가 필요하면 toolbar의 실시간 녹화를 사용하십시오.

11.3 비디오 변환기

WebM→MP4 또는 JPG sequence→MP4를 변환합니다. sequence FPS, CRF, speed preset과 output path를 지정할 수 있습니다.

비디오 변환기는 native desktop 기능입니다. Browser-only 실행에서는 메뉴가 보여도 Desktop-only 오류가 발생할 수 있습니다.
