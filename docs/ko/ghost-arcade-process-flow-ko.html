레이어 ordering 불변식

Layer list는 render plan에서 reverse되어 UI 목록 상단 layer가 시각적으로 위에 합성됩니다.
비가시 layer, group child, renderable texture가 없는 layer는 해당 frame 합성에서 제외됩니다.

GPU fallback

Project resolution이 GPU texture/renderbuffer 한계를 넘으면 clamp합니다.
RenderTarget allocation 실패 시 64×64 safe target으로 계속 진행합니다.
Master warp renderer 실패 시 검은 화면 대신 raw base canvas를 사용합니다.

7. 핵심 불변식과 문서 유지 규칙

Locale
en | ko만 지원하며 알 수 없는 값은 영어입니다.
Identifier
Effect ID, display ID, targetType, MIDI/OSC path, IPC payload, protocol/persisted value는 번역하지 않습니다.
Store
렌더 입력의 정본은 project writable store이며 UI·mobile·output은 이를 직접 또는 sanitize snapshot으로 소비합니다.
Runtime object
Texture, render target, DOM/video/canvas는 저장·WS·BroadcastChannel payload에서 제거합니다.
Output priority
Zero-copy > WebRTC > legacy. 기능 설명에서 세 경로를 혼동하지 않습니다.
WebRTC 제한
현재 gamma/crop을 완전 지원한다고 문서화하지 않습니다.
Cursor shim
OutputWindow.updateCursorPosition/clearCursor는 현재 no-op이며 실제 cursor sync와 구분합니다.
Mobile security
LAN control은 신뢰할 수 있는 private network에서 사용합니다.
