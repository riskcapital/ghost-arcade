# Ghost Arcade Pro 2.1.7

## Flux and Randomize in VJ mode

The phone app's Flux pad now plays from the desktop, in the space beside the program preview.

- **Flux pad:** drag across the pad. Left and right change the character, up makes it stronger. Letting go releases it; **Stay on** keeps it running.
- **FX:** the button beside Wet / dry slides up the effect picker: twelve effects to combine (Liquid, Fold, Prism, Echo, Solar, Slice, Tile, Tunnel, Pixel, Glitch, Ink, Pulse), the blend mode and Beat lock. Click it again for the full pad.
- **Randomize:** throws every playing shader and effect setting to a new random value, like Tab in Performer. The gear chooses Shader + FX, Shader only or FX only. Press the button, press **Tab** in VJ mode, or map it to MIDI (`vj:flux:rnd`).

Flux also takes MIDI on `vj:flux:on`, `vj:flux:x`, `vj:flux:y` and `vj:flux:mix`.

## Flux plays inside each Screen

In VJ Stage mode, Flux now plays inside each Screen on its own, so a Fold or Tile repeats within every screen instead of warping the stage as one picture. Mapping mode does the same with its Screens. In VJ Mix mode Flux plays on the whole mix. This applies to Flux from the desktop and from a paired phone.

## Stage Sim follows the program

- Each Stage Sim screen shows its own slice of the program picture, the same slice the outputs show, so the deck mix, composition effects and Flux all appear on the stage.
- Audio-reactive shaders react to the music in Stage Sim.
- Closing and reopening Stage Sim keeps the venue, lighting, beams, haze and placed objects, and they save with the project.

## Fixes and smaller changes

- A project started from a template and saved now reopens with its shaders and Performer clips, instead of reporting their files as missing.
- Point cloud and 3D model layers keep their data when hidden and shown again.
- Light Painting has a **Head Feather** control (Animation → Timing) that softens the leading edge of the draw animation instead of a hard cut.
- With the deck A/B monitors showing, the program preview sits centred over the decks and the two monitors beside it match its height.
- The text font menus list only fonts installed on the computer.
