# Ghost Arcade v1.9.99

Sharper live triggering, richer LED performance, expanded VJ sources, and more reliable control.

## Highlights

- Armed VJ videos reuse their warmed texture on launch, avoiding the black-frame flash that could briefly expose layers beneath a new clip.
- Blend-mode influence now follows layer opacity, with normal opaque coverage at 100% and the strongest blend interaction around the midpoint.
- Master corner and mesh warp points support the same configurable keyboard nudge sensitivity used throughout Mapping Mode.
- Dropdown and drag state cleanup is hardened for long sessions so selectors remain responsive after repeated editing.
- LED FX uses a compact pattern selector and adds solid, gradient, alternating, block, random, and wave color layouts with one to four custom colors and performance-ready palettes.
- GPU Shader and Text Creator sources are available directly from the VJ plugin library with dedicated icons and editing panels.
- Eight new audio-reactive ISF visuals join the bundled library alongside the original Warp Loom GPU shader.
- OSC bindings expose stable routes for VJ clips, mapping presets, transport, crossfader, macros, and LED effects, with a documented Pro DJ Link bridge workflow.
- The desktop app keeps the display awake and prevents the screensaver while Ghost Arcade is running.
- Two unfinished generated shader entries were removed from the user shader manifest.
