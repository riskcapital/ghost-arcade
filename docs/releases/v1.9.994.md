# Ghost Arcade v1.9.994

The interface follows your Windows display scale.

## The UI was drawn tiny on scaled Windows displays

On a Windows machine set to 125%, 150% or 200%, Ghost Arcade drew its
interface at 100% while every other app respected the setting. The only way
to read it was to change the display scale for the whole machine, which
changes everything else along with it.

The app was overriding the device scale factor at launch, a switch that had
been in the code since the 0.5.0 fork and was never needed. It is gone, and
the window now scales the way the operating system says it should. macOS is
unaffected, because it already followed the display scale.

This is the same change that shipped in 2.0.5, brought back to the 1.9 line
for anyone whose machine 2.0 does not suit. Nothing else is different:
1.9.994 is 1.9.993 with that one switch removed.
