# Ghost Arcade 2.0.18

## Text that moves like a title sequence

The Text layer has a new set of kinetic animations, a tiling mode and a reader for long text.

- **Kinetic animations.** Stretch Wave and Elastic Wide make letters grow wide while the rest of the line moves aside for them. Tall Stretch, Size Cascade and Tracking Breathe change height, size and spacing. Echo Stack, Drum Roll and Orbit stack copies, roll letters over and run the text around a circle. Slam and Rise are new entrances.
- **Tile the text.** Repeat the text across the layer in eight patterns: Grid, Brick, Sizes, Vertical, Scroll, Flip, Steps and Mix, with up to 12 columns and rows. Tiling works with any animation.
- **Read through long text.** Load a text file of any length and show it a word, a phrase, a line or a page at a time. Set the pace in words per minute, or step on the beat. The chosen animation plays for each piece.
- **React to audio.** An Audio amount and a band to follow (level, bass, mids, treble or beat). Quiet passages calm the motion and loud ones push it.

All of it is under **Repeat and Read** in the Text panel and the VJ text clip panel.

## Painting studio

With the iOS app (1.1.1) paired, Auto map can pick out a painting on the wall.

1. Run an Auto map scan with the painting in view, then tap **Painting on this wall?** on the phone. Drag the corners if the outline is off.
2. Send it to the desktop and click **Create layers**. The cropped photo arrives on a layer lined up with the painting.
3. Under **Cut the painting into shapes**, set **Detail** and create one mapping layer per patch of colour. Stage effects can then run across the shapes.

Two new effects suit a projected picture: **Paint Drip** runs the image down in wet drips, and **Ink Flow** carries colours into each other along a moving stream.

A very high shape count costs frame rate. Start with a low Detail setting.

## HandFX: body and face

HandFX gains five modes driven by body and face tracking: **Particle Body**, **Force Field**, **Aura**, **Mask** and **Breath**. The existing hand modes have three times the particles. Body and face tracking can also be switched on in the MediaPipe panel and bound to any control.

On macOS the app now asks for camera access before tracking starts, and shows a message if the camera opens but sends no picture.

## Flux from your phone

Flux on a paired phone can now play on the desktop's outputs. Open **Tools → Desktop → Flux** on the phone.

## MIDI

- Browse and load from the Media Library, start and stop recording, tap tempo and step blend modes from a controller.
- Load and save MIDI mappings as a file, with a choice to replace or merge.
- Ready-made layouts and an overlay sheet for the QuNeo.

## Security

- The editor can now write and read only files you chose in a dialog, your project file, and the app's own asset folder.
- The render core no longer accepts file paths from the editor for reading, deleting or overwriting.
- Network requests through the app are limited to the services it uses.
- Hydra layers run only the sketches that ship with the app.

After upgrading, a project recovered from autosave may show media from other folders as missing. Open the saved project file, or add the media again, and it loads.

## Shader library

Nine shaders converted from other authors' work have been removed. Projects that used them still open; those layers show as empty.
