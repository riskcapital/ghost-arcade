# Ghost Arcade 2.0.17

## Auto map from your phone

With the Ghost Arcade iOS app (1.1) paired, the desktop can map a projector by itself. The projector flashes a short series of stripe patterns, the phone watches from a tripod, and every flat surface the projector lights is found and comes back as a media layer already pinned to that surface. No corner dragging.

1. Open the Screen on the projector (**Screens → Open on display**).
2. On the phone: **Tools → Calibration → Open camera**, prop it near the projector, **Start scan**.
3. Switch off any surface you do not want, then **Send to desktop**.
4. On the desktop, **Create layers**.

It finds flat surfaces. Curved or uneven ones still need a mesh by hand. A re-scan replaces the layers from the last scan unless you untick that.

## Projector calibration

- Typing a number no longer applies half-typed values; arrow keys nudge a corner by one pixel (Shift ten, Alt a tenth).
- **Show alignment grid** and **Identify** on every Screen, and a **Projector gamma** for the shared overlap.
- Paired Screens stay in step when either one's overlap is edited.
- A display connected after launch can be used without restarting.
- A phone calibration with corners traced in a different order no longer mirrors the picture.

## macOS outputs are truly full screen

Output and Screen windows now sit above the menu bar and cover the whole display, including when another app is in front or displays have separate Spaces.

## Interactive Studio

- Keyboard shortcuts no longer leak through to the editor behind it, undo and redo are reliable, rotation no longer shears shapes.
- Styles have real alpha and a working opacity, and moving a slider updates the scene in place instead of resending it.
- The Liquid effect has been withdrawn. Scenes that use it still play.

## Editor

- An empty media layer shows an alignment card on true black instead of a grey fill, and the composition backdrop is true black.
- The top bar keeps every control and label visible and scales to fit a narrow window instead of dropping labels. The audio strip is always present. Record and its source menu are one control.
- Fifteen featured shaders load by default after the utility shaders.
- Point clouds: Solid Points, steadier framing, and scans sent from the phone arrive in the Media Library.

## Windows

- Spout, Syphon and NDI Screen senders, the sender atlas and the WebGL Master Warp no longer darken mid-tones.
- Seeking video starts from where the stream really begins.
- The render loop no longer spins while an effect compiles, which could time out the core at startup.
- Performer worlds stay visible in Tunnel space.

## Linux

Linux builds are published again as an AppImage and a deb (X11 with a Vulkan driver). The editor, Screens, calibration, Interactive Studio, VJ mode and the Output Window are checked on every change on Ubuntu. Two limits: recording a single layer or with transparency is not available on Linux (record the composition instead), and video is decoded in software.

## Verification and scope

Checked on macOS: engine tests, type checks, the unit and GPU suites, and a build. Checked on Ubuntu runners with software Vulkan: the list above, and installing the packages on clean Ubuntu 22.04 and 24.04. Auto map was proven on one projector and one scene (a box on a floor) with an iPhone 12 Pro Max.

Not checked: this exact build on Windows hardware, Linux on a real GPU, two projectors mapped at once with Auto map, and a second display for the macOS full-screen fix.
