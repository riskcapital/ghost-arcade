# Ghost Arcade 2.0.10

A patch for 2.0.9: HAP playback takes less CPU, the automatic tempo control is
always in view, and the render core no longer adds a second icon to the Dock on
macOS.

## Lighter HAP playback

HAP clips take less work to get onto the graphics card. Ghost Arcade reuses its
upload memory instead of allocating it fresh for every frame, and sends the HAP
frames that are ready together to the GPU in one batch. Video playback also no
longer builds reduced-size copies of every frame, which it never used. With four
1080p HAP clips playing, the renderer used about 28% less CPU for the same
frames.

## Automatic tempo is always in view

The AUTO button beside the BPM field now stays in place and shows what the tempo
is doing: Waiting for audio, Detecting tempo or Following audio. After you type
or tap a tempo it reads Use audio tempo; click it to go back to the detected
tempo. With no audio connected, the BPM field no longer shows a stale number.

## One Dock icon on macOS

The render core now runs as a background helper, so it no longer adds a second
icon to the Dock or takes focus when it starts. Output windows work as before.

## Good to know

The HAP upload changes have been tested on macOS. Windows uses the same code,
but it has not been played back on a Windows machine yet. If a HAP clip plays
incorrectly on Windows, please tell us.
