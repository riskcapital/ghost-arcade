# Ghost Arcade 2.0.16

## Windows projector output fix

Fixed Windows Screen outputs ignoring projector calibration, corner/mesh source warping and paired overlap blending. The native renderer incorrectly reported Screen presentation as unavailable on Windows, selecting an older browser output path instead of the calibrated DXGI texture.

Screen windows now use native output regardless of the legacy zero-copy preference. On Windows/macOS, an unavailable native presenter reports an error instead of silently opening an uncalibrated fallback. The Windows presenter checks for named-texture support before opening an output.

## After updating

1. Restart Ghost Arcade, load your project, and reopen each Screen output on its assigned display.
2. Test one projector at a time. Under **Screens → Projector calibration**, enable **Correct output geometry** and move the top-right corner's Y value to **30%**. The projected picture should visibly change immediately.
3. Reset that corner, then align the two projectors using one full-width grid. Enable **Angled two-projector overlap**, select the partner screen, and click **Pair blend & set overlapping crops**.
4. Keep the fade inside the area covered by both projectors. Re-pair after editing overlap boundaries, then refine destination corners if the crops changed.
5. Switch full-width VJ clips and save/reopen the project to confirm calibration persists.

Do not add a second legacy feather to the shared seam. Doubled details indicate geometric misalignment, not a need for more feathering. If moving a destination corner still has no visible effect, stop calibration and report the Screen output error.

## Verification and scope

Windows-target compilation, native presentation capability tests, Electron output-routing tests, desktop type checks and frontend build passed. GPU tests read the actual exported Screen textures and verify angled overlap, corner correction, changing content, and live edits without replacing the output handles. These GPU checks ran on macOS; physical Windows projector acceptance remains pending.

All 2.0.15 features remain included, including **Neo Industrial** in **Settings → Appearance → Theme Template**, expanded GhostFX/HandFX, and paired projector calibration.
