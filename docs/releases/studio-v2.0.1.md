# Ghost Arcade Studio 2.0.1

## Your settings are back

Ghost Arcade Studio 2.0.0 opened with default settings, an empty autosave and an unpaired phone, as if it were a fresh install. Nothing was lost: 2.0.0 looked for its data in a new folder by mistake, and everything you had stayed in the folder every earlier version used.

2.0.1 goes back to that folder, so your settings, the project autosave, your phone pairing and your imported media are all there again.

- If you changed settings or worked on a project in 2.0.0, save that project from 2.0.0 to a file before updating, then open the file in 2.0.1.
- If you started on 2.0.0, with no earlier version installed, Studio keeps using the folder 2.0.0 made.

## Also fixed

- **macOS:** Studio offers once to move an old 1.9 app to the Trash. It now finds it under its real name, "Ghost-Arcade.app".
- Studio and Ghost Arcade Pro 2.1.4 run side by side, each with its own data, pairing code and phone ports.

## Updates

Studio tells you when a new Studio release is out: a window opens once for each new version. It never offers Ghost Arcade Pro, which needs a newer kind of graphics card.
