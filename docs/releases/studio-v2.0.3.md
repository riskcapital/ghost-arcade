# Ghost Arcade Studio 2.0.3

## Fourteen p5.js sketches built in

The JS tab of the Media Tray now ships with fourteen p5.js sketches, each with its own thumbnail and controls.

- **Six shader sketches:** Aurora Veil, Moire Bloom, Liquid Chrome, Neon Cells, Kaleido Mandala and Truchet Circuit.
- **Eight canvas sketches** that play to what p5.js does best: Flock (a murmuration of boids), Ink Flow (ink agents writing calligraphy), Growing Tree (recursive growth), Differential Growth, Circle Pack, Contour Lines, Beat Tiles and Kinetic Type.

## Text boxes, menus and colour pickers

A JS page can now declare text and menu controls as well as sliders, switches and colours, and colour controls get a picker in the Media Tray. Kinetic Type uses them: type your own words, pick a font, and the letters re-form live.

## Transparent sketches

The eight canvas sketches have a **Transparent** switch: turned on, their trails fade to clear instead of black, so the marks float over the layers below with any blend mode.

## Better AI-generated p5.js

AI Generate → p5.js now asks for sketches built on p5's strengths, with labelled controls including text boxes and menus, the Transparent switch, and a 1080p performance budget. Generated pages get their control labels and ranges.

## Write your own

The new guide at https://ghostarcade.live/docs/p5js covers writing a sketch by hand or with ChatGPT, Claude or Cursor, and https://ghostarcade.live/skills has a p5.js skill file for AI assistants.

## Fixes

- JS tiles in the Media Tray show their thumbnails instead of a type icon.
- On macOS, when system audio cannot start because Screen & System Audio Recording permission is off, the error now says where to turn it on.
