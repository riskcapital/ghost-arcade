# Ghost Arcade v1.9.98

Reliable stage presets, a complete WLED performance suite, and restored loop transitions.

## Highlights

- Stage effects now work across every recalled stage preset instead of only the newest preset.
- WLED output remains active while switching presets and now includes Auto, Strip, Matrix, and Custom spatial maps; source-region cropping; serpentine and reverse wiring; linear-light per-controller color matching; live shader palette sampling; and LED-order, chase, and solid-color test patterns.
- LED FX in VJ Mode provides 47 patterns across Movement, Organic, Rhythmic, Spatial, Content Aware, and Glitch collections. Effects can latch, run while a mapped button is held, stack with blend modes, sync to BPM, or advance automatically.
- Named physical ranges support multiple strips on one WLED controller, while LED groups combine ranges across controllers. Every effect can target the whole rig, one controller, one range, or one group.
- LED effect latch and hold actions are assignable to MIDI and computer keyboard controls for live chase, firefly, wave, strobe, shader-color, and glitch performance.
- VJ videos display upright and unmirrored by default.
- Video Loop Creator restores the full grouped transition library, including the expanded glitch and custom Ghost transition styles.
