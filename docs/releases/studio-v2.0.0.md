# Ghost Arcade Studio 2.0.0

## The 1.9 line is now Ghost Arcade Studio

The Ghost Arcade line that renders through the browser engine is now called **Ghost Arcade Studio**. It runs on more machines than any other version, older computers and integrated graphics included. It keeps getting fixes and releases.

The native-engine line (2.x) is now **Ghost Arcade Pro**. It needs a modern GPU and does heavier work. The two are separate apps: they install side by side, and both can run at the same time. Projects open in both.

Studio 2.0.0 is the same app as 1.9.996, under its new name and ready to sit beside Pro.

## Updating from 1.9

- **Everything stays.** Studio uses the same data folder as every earlier version, so your settings, the project autosave, your phone pairing and your imported media are all still there.
- **Windows:** the installer upgrades your Ghost Arcade install in place. The app, shortcuts and Start menu entry are now called Ghost Arcade Studio.
- **macOS:** the app is now "Ghost Arcade Studio" in Applications. On first launch it offers once to move the old 1.9 "Ghost Arcade.app" to the Trash. Choose Keep to leave it where it is.
- **Linux:** the .deb keeps its `ghost-arcade` package name, so it upgrades the installed package. The AppImage file is now named Ghost-Arcade-Studio.
- **macOS and Linux:** if you were signed in to ghostarcade.live from the app, or saved PJLink projector passwords, enter them once more. They are encrypted for each app name.

## Running beside Ghost Arcade Pro

- **Phone link:** when Ghost Arcade Pro already holds the phone ports (9001 and 9002), Studio moves to the next free pair. The QR code carries the right address, and the phone page now reads it, so a phone that scans the code connects to the right app.
- Each app keeps its own pairing code, its own settings and its own window.

## Updates

Studio tells you when a new Studio release is out: a window opens once for each new version, and the version in the status bar offers it after that. It never offers Ghost Arcade Pro, which needs a newer kind of graphics card. Get Pro from the download page if your computer has one.
