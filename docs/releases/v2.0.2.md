# Ghost Arcade 2.0.2

Composition FX, Ableton Link phase, and media that survives a save.

## Composition FX now actually do something

Composition-level effects reached the renderer only through the
compositor's nine inline colour ops, and everything else was silently
dropped. Anything that samples neighbouring pixels — blur, kaleidoscope,
colorama, pixelate — had nowhere to run, which is why the picker offered
effects that did nothing.

Composition FX now run the same effect-pass chain that layer and clip FX
already used, so each effect gets its own pass and a real input texture.
Working in both VJ and mapping mode; mapping runs it as a post-composite
pass in the core.

## Ableton Link follows phase, not just tempo

Link carries a phase as well as a tempo, and Ghost Arcade was reading
only the tempo. Matching BPM while ignoring phase is what put clips
reliably off the beat.

- A 1-2-3-4 beat indicator with the downbeat marked, so an offset bar is
  visible at a glance rather than inferred from the music.
- Clip triggering quantized to the session phase.
- Peer count and quantum readout, because "BPM matches but I'm off the
  beat" was impossible to tell apart from a wrong quantum or no session.

## Fixes

- **Spout inputs froze on the frame they were added** (Windows). The
  upload signature keyed on the sender-reported frame number, and the
  Spout SDK leaves that at zero unless frame counting is switched on in
  SpoutSettings. Receives are now counted host-side. Syphon was unaffected
  because it reports its own counter.
- **Image clips had no size or transform controls.** Zoom, fit, anchor,
  rotation, opacity and mirror were gated on the clip being a video in
  three separate places. Images are plain 2D media in the same quad and
  now get the identical controls.
- **Media dragged in from outside the filesystem saved as a dead link.**
  Files that do not come from the OS filesystem — dragged out of a
  browser, handed over by a sandboxed app — have no path on disk, and the
  project stored only a session URL that died on quit. Those files are now
  persisted when they arrive. Existing projects already saved in that
  state cannot be recovered and need relinking.
- Composition FX no longer flicker; the effect chain stays resident in the
  core instead of being re-queued against a different clock.
