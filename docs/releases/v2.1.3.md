# Ghost Arcade Pro 2.1.3

## Ghost Arcade Pro

The 2.x line is now called **Ghost Arcade Pro**. The 1.9 line becomes **Ghost Arcade Studio**. Both are fully maintained:

- **Pro** renders through its own native GPU engine. It needs a modern GPU and does the heavier work: big VJ decks at full resolution, up to 1024 layers, and the Stage and Map simulators on the render core.
- **Studio** renders through the browser engine, so it runs on more machines, older computers and integrated graphics included.

The two are separate apps now. They install side by side, and both can run at the same time.

- **Your settings come with you.** On its first launch Pro copies the settings, preferences, project autosave, shaders and file permissions from the old Ghost Arcade folder. Imported media stays where it is, and projects still find it.
- **Pair your phone once more.** Pro has its own pairing code, so a phone paired with Studio cannot drive Pro without being paired to it.
- **Both apps at once.** When Studio already holds the phone ports (9001 and 9002), Pro moves to the next free pair. The QR code carries the right address, so a phone that scans it connects to the right app.
- **Windows:** installing Pro removes the old 2.x "Ghost Arcade" install and keeps its data. Ghost Arcade Studio is never touched.
- **macOS:** Pro installs as "Ghost Arcade Pro". On first launch it offers once to move an old 2.x "Ghost Arcade.app" to the Trash. Choose Keep to leave it where it is.
- **Linux:** the .deb is the `ghost-arcade-pro` package, so it installs beside Studio's.
- **macOS and Linux:** if you were signed in to ghostarcade.live from the app, or saved PJLink projector passwords, enter them once more in Pro. They are encrypted for each app, so Pro cannot read Studio's copy.

## Ableton Live bridge

Ghost Arcade now connects to Ableton Live. A control surface script reports Live's session to Ghost Arcade on the same computer, and the new Ableton tray in VJ mode drives the visuals from it. It works with Live 10, 11 and 12, on Windows and macOS. No Max for Live is needed.

- **Setup from the tray.** The tray installs the script into the User Library that Live uses, finds which Live you have, and names the exact menu and tab to turn it on in: Options → Preferences on Windows in Live 10 and 11, Options → Settings in Live 12, Live → Settings on macOS. A green dot on the Ableton button beside QUANT shows when Live is connected.
- **Link Live to visuals.** Drag a column, clip, snapshot or Stage preset onto a Live scene, clip or locator, and it fires the moment Live launches it, on the same bar. Links follow scenes and clips by name when the set is rearranged, and they save with the project. Auto-map links scenes to columns, tracks to layers, songs to columns or song parts to columns, whichever fits the set.
- **Session view over the decks.** The tray slides over the deck area, so the program output stays in view. It has Live's transport, tempo, bar counter and launch quantize, Live's grid with a thumbnail of what each cell launches, and countdowns to queued launches.
- **Setlist and autoplay.** Every song in the set is listed in your order, with its BPM, deck, visuals and sections. Play any song or press Next. Autoplay can follow each song's plan section by section, or play the whole set.
- **Two-deck DJ sets.** A set with Live tracks on both crossfader sides links its decks to Ghost Arcade's A and B decks, and the crossfaders move together in both directions. Each crossfader has a Linked / Live only switch. Auto-mix eases the crossfader over 4, 8 or 16 bars when a song lands.
- **Score.** A MIDI track named "Ghost Arcade" plays visuals from Live's piano roll: each pitch is a lane that fires a column, snapshot or any control, in time with Live, and follows tempo and loops.
- **Beat scramble.** The tray's Scramble control randomizes the shader or effect settings on the deck the crossfader shows, on Live's beat, from every beat to every four bars.
- **Signals.** Any device knob, rack macro, track level or loop position in Live can drive any Ghost Arcade control, with range, invert and smoothing.

## Also new

- **The VJ deck bar fills its row.** Rows, columns, tap tempo, nudge, audio in and out, QUANT and the Ableton button spread across the full width, and wrap one by one on a narrow window.
- **Translations.** The Ableton tray, the guided tour, the templates, the Linux GPU notice and Map Sim auto-map are translated into Spanish, German, French, Portuguese, Italian and Japanese. Names from your Live set always show as Live has them.

## Fixes

- **Spout on Windows:** the native output finds the graphics adapter it renders on, and it retries native sharing after a fallback to window sharing.
- **Deck A/B monitors on Windows:** the monitors stay behind the editor window when it comes to the front, instead of showing the app that was in front before.
- **Control paths:** `vj:fx` paths keep effect ids and parameter names as written, values are held to each parameter's range, and group effect paths find effects whose ids have capitals.
