# Ghost Arcade Pro 2.1.5

## Captured windows at full resolution

A window or screen added as a Capture source came in at a lower resolution than it shows on screen, so slides and other sharp content looked blurry, however large the window or the canvas.

- **macOS:** the capture now uses the screen's real pixel size. On a Retina screen it used to take half the pixels in each direction. It also follows the window: resize it, or move it to another screen, and the capture keeps up instead of staying at the size it started with.
- **Where the native capture is not used,** captures were limited to 1920 × 1080. They now go up to 4096 pixels on each side, in the window's own shape, so 4K slides and square dome masters stay sharp.

For a sharp 4K picture end to end, set the canvas to 3840 × 2160 (4K) in Settings, or a custom size such as 4096 × 4096 for a dome master.
