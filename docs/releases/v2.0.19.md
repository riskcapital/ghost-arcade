# Ghost Arcade 2.0.19

## Clips play their sound as soon as you add them

In 2.0.18 a video clip you dropped or picked onto the VJ deck played without sound until the project was saved and reopened. The Audio Out panel showed "Output active" with 0 clips prepared. Clips now play their sound straight away.

Clip audio also opens on more output devices. Sound cards and audio interfaces that present 24 or 32 bit integer output used to get no audio stream.

## Missing clip files

Files get moved, renamed or unplugged while a show is open.

- A clip whose file is no longer on disk shows a **?** on its cell, and a bar above the deck says how many clips are affected.
- **Search a folder** looks through a folder and its subfolders for the missing file names and relinks every clip it finds, so a pack that moved is fixed in one step.
- **Choose file** relinks one clip. Other clips on the same file follow.
- The deck checks again every few seconds, so a file that comes back clears its mark by itself.
- A clip with no file no longer restarts its decoder every second, which used to pull the frame rate down for the whole show.

Save the project after relinking to keep the new locations.

## Build a stack faster

- **Fill a row.** Hover a clip and drag either bottom corner sideways. Every column you pass gets that clip. A clip filled across a row keeps playing when you fire another column, so a background stays put under the layers that change.
- **Reorder rows.** Drag a row by the handle on its LIVE thumbnail and drop it anywhere on another row. A line shows where it will land.

## Interactive Studio: a look for each object

Select an object in the Objects tab and set **Appearance**:

- **Drawn by the effects** is how objects have always looked.
- **Custom** lets you choose what is inside (contours, weave, ripples, bands, spiral, grid, stripes, dots, checker, noise, a solid glow, or nothing), with brightness, detail, motion, outline strength and the object's own colour.
- **Invisible** draws nothing. The object still blocks, emits, attracts or triggers.

## 3D layer

A model that fails to load now says why, instead of leaving an empty layer.
