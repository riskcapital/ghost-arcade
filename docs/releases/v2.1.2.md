# Ghost Arcade 2.1.2

## Spout output reaches receivers on more Windows machines

On some Windows PCs the Spout sender said it was created but never appeared in receivers such as OBS or the Spout Demo Receiver. Ghost Arcade chose which graphics adapter to share through by looking for the first NVIDIA or AMD adapter, but a bug let a later adapter replace the first one. On machines that list the same graphics card more than once, the sender then opened on the wrong adapter and nothing was shared.

- The first NVIDIA or AMD adapter is now kept, so the sender opens on the same adapter that draws the output.
- If native Spout sending keeps failing for any reason, Ghost Arcade falls back to its window-based sharing instead of staying silent.
- The log names each graphics adapter with its ID and reports both error codes when a shared texture cannot be opened, which makes the next report much easier to trace.

Thanks to the user who traced this and verified the fix in OBS.
