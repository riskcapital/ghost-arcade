# Ghost Arcade 2.0.14

## Connect Mobile QR fix

Fixed Connect Mobile failing to display its QR code in installed desktop builds. Opening the panel before local network discovery completed could construct an invalid URL and interrupt rendering. The panel now waits for a valid network address and shows connection guidance when none is available.

The fix applies to the shared macOS, Windows and Linux desktop interface. Regression coverage includes packaged file URLs on all three platforms, LAN pairing tokens, custom ports and IPv6 addresses. macOS development testing was confirmed; Windows hardware testing is not claimed.

All other features and platform limitations remain as documented in 2.0.13.
