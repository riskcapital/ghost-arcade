# Ghost Arcade Pro 2.1.8

## Light Painting plays like Studio

Light Painting playback in Pro now follows the same timeline as Ghost Arcade Studio.

- **Strokes hold.** Strokes draw one after another, in the chosen sequence order and with the stagger delay, and each finished stroke stays on screen while the next one draws, until the loop starts again. Before, a finished stroke hung for a moment and then disappeared while the next one was drawing.
- **Loop modes.** Forward plays the drawing from empty to full and starts again. Reverse un-draws the drawing, last stroke first. Ping Pong draws, holds for the **Ping Pong Hold** time, un-draws and holds again. Once draws through and stays.
- **Tapered ends.** Stroke ends taper in width and brightness over their first and last fifth, and the glow rounds off around the tip, instead of ending on a hard line.
- **Trail.** Trail Length fades the tail of each stroke the same way Studio does.
