# Ghost Arcade Pro 2.1.9

## Merge VJ blocks

Right-click a block tab, pick another block under **Merge into this block** and press **Merge**. That block's clips move into the one you right-clicked, on both decks. Its columns go after the last column this block uses, in the same order, so each column still launches as the same scene, and the grid gains as many columns as it needs, up to 64. A clip already in the row is not added twice, and the merged block is removed.

## Autopilot across blocks

Autopilot has **Use clips from all blocks**. The layer steps through, or draws at random from, its row in every block, and plays clips from other blocks without switching the block on screen.

## The A/B slider between whole decks

- In Mix output, the slider's transition and blend mode work whatever rows each deck uses. Before, they only applied where both decks had a clip on the same row, and otherwise the slider did a plain fade. Stage keeps the per-row pairing, since each Screen shows one row.
- With a blend mode other than Normal, the move is one transition from A to B. Deck B comes in combined with A by the blend mode and settles into plain B as the slider reaches B. Before, the whole picture passed through the blend at the halfway point, so it looked like two transitions.
- Cut to A and Cut to B from MIDI, OSC and the menu glide over the TIME beside the slider, like the buttons. Moving the fader takes over from a cut that is still gliding.

## Lines: Light Up, feathered heads and a working reset

- **Light Up** fades whole lines in and out by where they sit: a wave left to right, right to left or back and forth, or each line at its own random times, like a row of trees lighting up one by one. Set the speed, how many lines are lit at once, the fade and a dim level. It combines with the draw animation.
- The draw animation's leading edge can be feathered into a fade (**Head Feather**) or drawn thin (**Head Taper**).
- Draw Animation changes every line unless **This line** is picked, so turning it off no longer catches only the selected line. An animation set to Once now draws instead of starting finished.
- **Reset All Animations** puts every line's draw animation and motion, the stagger and Light Up back to their defaults and restarts them. Undo brings the settings back.
- A Lines layer draws up to 32 lines with 2048 points between them. It was 8 lines, and further lines were dropped.

## SVG rotation and the transform gizmo

Rotate X, Y and Z turn an SVG in every mode, not only 3D extrude: the picture rotates as a card with the same perspective as the 3D modes. Auto-spin stays with the 3D mode. The transform gizmo from 3D model and point cloud layers works on SVG layers too: Move, Rotate, Scale and Reset. The rotation sliders are in the **Position, Rotation & Scale** section.

The Art Alive preset is gone. Its settings were so slight that it looked like the original SVG.

## Point clouds load in the background

A PLY or splat that is slow to read, for example still downloading from iCloud or on a network drive, no longer locks the window. The loading screen has **Continue in background** (or press Escape): the project stays usable and a small corner chip shows the load until the layer appears. Progress now moves as the file is read.

## 3D model deformations

The Deformation panel shows only the controls each deformation uses, and Axis offers only the axes it moves along, so no slider sits there doing nothing. Every deformation responds to its controls and looks the same on the native and WebGL renderers. Breathe is its own soft swell instead of a copy of Inflate, Melt's wobble follows Speed, and MIDI can reach all 21 types.

## MediaPipe and control bindings

- MIDI, OSC, DMX and MediaPipe bindings reach parameters whose names contain capitals, such as point size, a 3D model's deformation intensity, a GPU layer's background opacity and groups. They were written under the wrong name, so nothing moved. Bindings saved by earlier versions still work.
- A MediaPipe binding made in mapping mode drives the layer it was made on, not whichever layer is selected, and its label names that layer.
- During assignment, a hand position or pinch binds only value controls, so clips, tabs and buttons keep working and you can move to another shader without leaving assignment mode. A gesture can still bind buttons.
- p5.js and three.js sketch controls in VJ mode can be driven by MIDI and MediaPipe, parameters on deck B learn as deck B, and the crossfader blend mode binding works again.

## Fixes

- Switching a layer to another p5.js sketch no longer flashes the layers underneath. The layer keeps its picture until the new sketch, shader or image draws.
- Flythrough and Pixel Particles say **Select an input** instead of drawing a demo picture that looked as if your source had been lost. Switching between them keeps the input you picked.
- The count of queued launches is a badge on the QUANT box, so the deck toolbar no longer wraps when the media tray is open. The audio output button reads OUT and its volume.
