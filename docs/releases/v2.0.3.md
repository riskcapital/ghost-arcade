# Ghost Arcade 2.0.3

OSC in both directions, and screen setups that stay where you put them.

## OSC

Ghost Arcade now sends state back to your controller, not just takes it.
Faders follow the app, and clip buttons light when their clip is live.
Turn on Send feedback in Settings, OSC, and point it at your surface.
Feedback answers on the addresses you have already mapped, so there is no
second mapping to keep in step.

The template also covers far more of the app. It was clip and column
triggers plus three globals; it now installs per-layer opacity, blend,
solo, mute and video transport, block and snapshot recall, and mapping
mode, sized to your actual deck. That is 176 bindings against 83, and it
means the controls were always there, just not offered.

Full address reference in docs/osc.md.

### Following an external timeline

Send a clip's position as a 0 to 1 fraction on
`/ghost/vj/{deck}/layer/{n}/video/position` and the clip follows the
track, from Beat Link Trigger reading a CDJ, a DAW, or a show controller.

Send it continuously. Playback runs from an anchor, so between corrections
the clip advances at the right rate on its own, and a seek is only issued
once it has drifted. Sending at 20 to 50Hz will not make playback stutter.

`/ghost/vj/tempo` takes a BPM from a DAW. A live Ableton Link session
still outranks it.

## Screen setups

New projects now start from a clean output stage. Previously a new project
inherited whatever the last one left behind: its screens, and any dome,
warp or blackout still switched on. One user could not work out why their
output was stuck in a dome projection they had never chosen.

For a permanent install that is the wrong default, so the Screens tab can
now save the whole rig under a name, load one back, and mark one as the
default that new projects start from. An installed dome or projector wall
sets it once.

Display assignments, output resolution, Spout sender name and cursor
settings are left alone. Those are how the computer is plugged in, not
something a project decided.

The output preview also names any override that is transforming the
output, so a latched dome or blackout says so instead of leaving you
guessing.

## Fixes

- **Spout inputs froze on the frame they were added** (Windows). The
  upload signature keyed on the sender-reported frame number, which the
  Spout SDK leaves at zero unless frame counting is switched on. Confirmed
  fixed on Windows.
- **Clip position over OSC or MIDI did nothing.** It moved the browser
  video element, which is not what the native engine renders from. Same
  bug in mapping mode, fixed with it.
- **The OSC template stopped at a 4 by 8 deck**, so anyone who had added
  layers or columns had no bindings for them, including no column trigger
  past column 8.
