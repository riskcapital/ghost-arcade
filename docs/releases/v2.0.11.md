# Ghost Arcade 2.0.11

Windows deck previews and window controls, stage editing inside VJ, an
interface size setting, and fixes for reports from the forums and GitHub.

## Windows

- **Deck previews show video.** The A/B deck previews stayed empty on Windows.
  Both decks now show their video, update as it plays, and follow the display
  scale when you move the window between monitors.
- **Dropping a shader on a deck keeps the shader.** Windows adds a thumbnail
  image to the drag, and that image was imported instead, so a live shader
  became a still picture. Clips already made that way stay pictures; drop the
  shader on them again to replace them.
- **Empty decks no longer show the desktop** through the deck area.
- **Minimize, Maximize and Exit** are in the File menu on Windows and Linux,
  alongside the usual Alt+F4.
- **Built-in 3D sources load in the installed app.** In the packaged Windows
  build some generated entries pointed outside the app folder and failed to
  open.

## Stage editing inside VJ

Build and adjust the stage without leaving VJ. The Screens panel adds screens
as rectangles, circles, ellipses or stars, holds stage presets, and imports a
saved stage. The inspector sets what the selected screen or group shows: the VJ
mix, a single row, or a group. Screens draw their outline on the canvas using
the same corner and mesh transforms as the mapping renderer, so what you drag is
what the renderer shows.

## Interface size

Settings > App > Appearance > Interface size scales the interface from 75% to
200%, for high-resolution screens where the app was too small to read. The
setting is saved, and the native preview and deck previews scale with it. What
goes out of your outputs is unchanged.

## NDI output

Settings > Output > NDI Output shows whether your build can send NDI, with setup
steps and an error if starting or stopping fails. The Screens transport no
longer offers NDI based on input support, which is a separate thing.

What works today: on macOS, with the optional NDI addon and runtime installed,
Ghost Arcade sends one full composition. Per-screen senders with their own crop
and warp are not part of this. Windows composite NDI output is not supported
yet, and installing NDI Tools does not add it. The panel says so rather than
offering a switch that cannot work.

## Playback and media

- **Timeline position moves the picture.** Dragging a clip's timeline set a
  clock the native engine does not draw from, so the picture stayed where it
  was. VJ and Mapping now share one path into the native playback clock.
- **The crop window shows the source.** Setting a source crop now previews the
  live picture from the renderer while you drag the handles.

## Fixes from your reports

- **Lines: Edit Points moves points again.** Choosing Select left the tool in
  drawing mode, so vertices could not be moved, and the Edit Points button
  changed the layer selection as you pressed it.
- **Older OSC bindings keep working.** A saved `vj:layer:0:opacity` now resolves
  to `vj:0:opacity`.
- **Restart can be learned to MIDI** in both Mapping and VJ.
- **The OSC reference explains manual bindings.** Parameter paths use colons and
  count from 0; the template's OSC addresses use slashes and count from 1.

## HandFX

Three new looks, Energy Bridge, Orbital Field and Laser Fan, with eight color
palettes and a rehearsal mode that plays two virtual hands so you can audition a
look with no camera.

## Good to know

Windows playback was tested on an NVIDIA GeForce RTX 4070 laptop. Three 1080p60
sources held 60 fps in HAP, HAP Alpha and HAP Q, and a twelve-clip grid launched
without falling back to software decoding. AMD and Intel graphics use the same
path with less testing so far.

NDI network output has not been qualified on Windows: the test machine has no
NDI SDK, so the sender could not be exercised there.
