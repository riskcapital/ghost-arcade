# Ghost Arcade Pro 2.1.4

## Pro gets its own settings, and no keychain question

Ghost Arcade Pro 2.1.3 still kept its data in the folder the earlier versions used, the same one Ghost Arcade Studio uses. That had three effects on macOS and Windows:

- macOS asked for your keychain password, because Pro was reading a key that the earlier app had created.
- Pro and Studio could not run at the same time: whichever opened second closed again.
- The settings Pro was meant to copy were never copied, because it looked for them under the wrong folder name.

2.1.4 gives Pro its own data folder and its own keychain key:

- **No keychain question.** Pro creates its own key, so macOS has nothing to ask about.
- **Your settings come with you.** On its first launch Pro copies the settings, preferences, project autosave, shaders and file permissions from the earlier folder. Imported media stays where it is, and projects still find it.
- **Pro and Studio run side by side.** Each has its own folder, its own pairing code and its own phone ports.
- **macOS:** Pro offers once to move the old 2.x app to the Trash. It now finds it under its real name, "Ghost-Arcade.app".

If you were signed in to ghostarcade.live from the app, or saved PJLink projector passwords, enter them once more in Pro. Pair your phone with Pro once.
