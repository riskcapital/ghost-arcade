# Ghost Arcade v1.9.99991 (2.0 Release Candidate)

A release candidate for Ghost Arcade 2.0. It carries the 2.0 feature set and
the native render core, and is versioned 1.9.99991 so it installs and updates
cleanly alongside the existing 1.9.x line while the release is being verified.

## Highlights

- The native render core (`ghost-render-core`) is now bundled with the
  application on every platform. Rendering, compositing, and output run in a
  dedicated Rust/wgpu process rather than in the browser context.
- Shared-texture output paths on macOS (IOSurface) and Windows (DXGI), so
  frames reach Syphon/Spout and the deck monitors without a CPU round trip.
- 180 effects across 21 categories, updated documentation, and the rebuilt
  ghostarcade.live site.

## Fixed since v1.9.9999

- The native render core could not start in a packaged build. The core was
  spawned with the app archive as its working directory, which is a file, so
  the spawn failed with ENOTDIR and the app opened into NATIVE OFFLINE on
  every platform despite shipping a working, signed binary. v1.9.9999 has
  been withdrawn; use this build instead.

## Release candidate notes

- This is a candidate build. If you depend on Ghost Arcade for live work, keep
  your existing install available.
- 2.0 requires the native render core. If the core cannot start, the app
  reports NATIVE OFFLINE rather than falling back to the previous renderer.
- The last non-native release, v1.9.993, remains available and supported. It
  is linked from the download page and will stay published.
