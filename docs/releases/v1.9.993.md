# Ghost Arcade v1.9.993

Professional point-cloud and 3D-model tools, more responsive VJ media, and live A/B deck monitoring.

## Highlights

- Gaussian splat and point-cloud layers gain robust large-file loading, improved color handling, orientation tools, a full 3D transform gizmo, animation and displacement controls, lighting, fog, transparent backgrounds, and modulation/keyframe support.
- 3D model layers gain expanded materials, lighting and shadow controls, deformations, aligned wireframe and vertex treatments, background transparency, and improved transform and performance behavior.
- VJ clip triggering and direct deck drag-and-drop are more responsive, with restored media paths and safer first-frame presentation.
- A/B mode now shows live Deck A and Deck B source monitors beside the Program preview.
- The deck monitors reuse the compositor's existing bank textures, avoiding duplicate source rendering, video decoding, or GPU readback.
- Native video and shader presentation receives additional resize, attachment, and stale-frame safeguards.
- Splat parsing now accepts valid complete records with harmless trailing file bytes.
