# Ghost Arcade 2.1.1

## The welcome screen opens on every launch

The welcome screen used to appear only the first time Ghost Arcade opened after installing. It now opens every time, so the tour, the templates and your saved projects are one click away whenever you start a session.

- Press **1** to **4**, or click a choice: take the tour, start from a template, open a project, or start blank.
- **Esc** goes straight to a blank project.
- Show mode still opens directly into the show, and a crash-recovery offer is shown on its own.
