# Ghost Arcade Studio 2.0.2

## Captured windows at full resolution

A window or screen added as a Capture source was limited to 1920 × 1080, so a 4K window, such as slides for a dome or a large display, came in scaled down and blurry however large the window or the canvas.

Captures now go up to 4096 pixels on each side, in the window's own shape, so 4K slides and square dome masters stay sharp.

For a sharp 4K picture end to end, set the canvas to 3840 × 2160 (4K) in Settings, or a custom size such as 4096 × 4096 for a dome master.

## Updates

Studio tells you when a new Studio release is out: a window opens once for each new version. It never offers Ghost Arcade Pro, which needs a newer kind of graphics card.
