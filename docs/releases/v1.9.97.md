# Ghost Arcade v1.9.97

Mapping precision, persistent masks, and hierarchy mattes.

## Highlights

- Mesh warp arrow nudges now use the global mapping movement granularity, matching corner, whole-layer, and fine-tune controls. Hold Shift for 10x movement.
- Done Editing Mask exits mask-point editing while keeping the mask enabled and visible.
- Existing masks can be reopened from the pencil control without interrupting corner or mesh warp work.
- A new Mask Layer type accepts no media and masks every layer beneath it in the hierarchy, including layers within groups.
