# Ghost Arcade v1.9.96

Hotfix: VJ media polish, mapping preset reliability, and MIDI clock routing.

## Highlights

- Expanded VJ Effect Bundle parameters now show the effect name at the top of the parameter list.
- VJ clip cells keep fixed sizing during image drag/drop, so rows and columns no longer grow unexpectedly.
- Still-image clips now get the same fit, mirror, zoom, anchor, rotation, opacity, and reset transform controls as video clips.
- Animated GIF image sources refresh in the renderer so output playback advances instead of freezing.
- Mapping media layers auto-rename to the dropped image or video name when the layer still has a generic media-layer name.
- Mapping presets and VJ blocks can be drag-reordered, with MIDI preset indexes following the visual order.
- Mapping presets containing videos rehydrate video elements when recalled, avoiding the Replace workaround.
- Settings now supports Cmd/Ctrl+, and MIDI Learn can be toggled with Cmd/Ctrl+M.
- MIDI clock can be received from a separate input while controller mappings stay on the main MIDI device.
- VJ video speed can be free-running or synced to 1 beat, 2 beats, 1 bar, 2 bars, or 4 bars at the master BPM.
