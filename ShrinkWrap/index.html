System Architecture

Distributed visual processing pipeline

A layered architecture separates content generation from compositing and output. Each stage runs independently on the GPU for maximum performance.

01
Shader Engine
100+ GPU-accelerated GLSL fragment shaders. Fractals, particle systems, kaleidoscopes, voronoi, plasma, sacred geometry, and generative visuals. All with real-time parameter control.
02
3D Compositor
Three.js scene rendering with camera automation and dynamic lighting. Import 3D models, create depth, and seamlessly integrate with 2D content layers.
03
Media Mixer
Import MP4, MOV, GIF, PNG, JPG. Layer content with 32 professional blend modes. Real-time opacity, timing, and playback controls for seamless mixing.
04
Mesh Warper
Precision projection mapping with adjustable mesh grids and 4-corner pinning. Map content to any surface shape with soft edge blending for seamless multi-projector setups.
OUT
4K Projection Output
60fps output to multiple displays and projectors. Built-in screen recording in WebM/MP4. Zero-latency rendering pipeline optimized for live performance.
Complete Toolkit

Everything for visual performance

Content Layers
01 — ISF SHADERS

100+ GPU Shader Engine

GPU-accelerated GLSL shaders using the ISF standard. Fractals, particle systems, kaleidoscopes, voronoi, plasma, sacred geometry. All with real-time parameter sliders. ThreeBody mega-shader: 30 orbital presets x 12 effect styles.

02 — MEDIA

Video & Image Mixing

Import MP4, MOV, GIF, PNG, JPG, WebM. Playback speed control, loop modes, chromakey, timelapse, and trim controls. 81+ chainable post-processing effects on every layer.

03 — 3D MODELS

Full 3D Pipeline

Import GLTF, GLB, FBX with skeletal animation. 16 material types, 15 deformations, 16 animation modes, echo/instancing with 18 patterns. Full camera, lighting, and audio-reactive control.

04 — GAUSSIAN SPLATS

Point Cloud Rendering

Render gaussian splats and point clouds (PLY, .splat). 12 animation types, 13 color effects, physics simulation, mouse interaction, and 8 displacement modes. 100+ parameters deep.

05 — LINES

Line Drawing & Mapping

Freehand and point-click line drawing with 15 stroke effects including glow, neon, snake, laser, and pipe. Progress-based draw animation for PVC pipe mapping and stage line work.

06 — LIGHT PAINTING

Brush-Based Painting

8 brush types (glow, neon, flame, electric, ribbon, particle, smoke, laser) with draw animation. Trail effects, bloom, afterglow, echo, and stagger modes for live painting.

07 — SVG

Animated Vector Graphics

Import SVG with 7 fill modes and 15+ advanced effects. Edge particles, energy pulses, lightning, plasma, connections, and more. Gradient, shimmer, liquid, and noise fills.

08 — TEXT

Animated Typography

18 text animation modes: typewriter, wave, glitch, rainbow, matrix rain, elastic, spiral, explode, and more. 3D extrusion with depth, lighting, and bevel. Full font and stroke control.

Effects Pipeline
09 — EFFECTS

81+ Chainable Effects

Drag-and-drop effect chains per layer. 16 categories: distortion, color grading, blur, stylize, generate, keying, light/glow, warp, atmosphere, text/pattern, 3D, depth, trails, and feedback.

10 — BLEND MODES

25+ Compositing Modes

Professional blend modes: add, multiply, screen, overlay, soft light, hard light, color dodge, color burn, difference, exclusion, hue, saturation, luminosity, and more.

Live Performance
11 — VJ MODE

16-Channel Clip Launcher

4 layers x 8 columns clip grid. Instant triggering, crossfades, compositions, and stage presets. Load any layer type into slots. Built for live shows.

12 — SYNTHVISION

36-Key Visual Instrument

Map any visual to keyboard keys. 4 rows, 36 slots. Save and recall keyboard presets. Full-screen performance mode. A visual synthesizer for live performance.

13 — SEQUENCER

Beat-Based Layer Automation

Timeline-based layer sequencer synced to BPM. Automate layer visibility and transitions. Quantized to beat grid with configurable time signatures.

14 — STAGE PRESETS

Instant Scene Switching

Save complete multi-layer configurations as stage presets. One click changes your entire visual environment. Perfect for scene transitions during live shows.

Control Systems
15 — MIDI

Full MIDI Mapping

Learn mode for any MIDI controller. Map CC, Note On/Off, Pitch Bend to any parameter. Multi-device support with channel filtering. Hardware control for every knob and fader.

16 — AUDIO

Audio-Reactive Visuals

6 frequency band analysis with beat detection. LFO modulation with sine, triangle, square, sawtooth waveforms. Drive any parameter from audio input for music-reactive performance.

17 — MOBILE

Wireless Control

Control from any device over WiFi. Touch-optimized interface for warp adjustment, clip triggering, and parameter control. Works with hotspot — no internet required.

Mapping & Output
18 — MAPPING

Precision Projection Mapping

Corner warp, mesh warp with adjustable grid density, per-element warp on individual shapes. Layer shape masks and soft edge blending for multi-projector setups.

19 — RECORD

Recording & Spout

Screen capture in WebM/MP4. Spout output for integration with OBS, Resolume, TouchDesigner, and LED controllers. 4K output at 60fps to multiple displays and projectors.
