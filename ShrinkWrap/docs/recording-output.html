Recording & Output

Capture your visuals, send video to other software, manage display outputs, and optimize for 4K performance.

Screen Recording

Record your visual output directly to video files without any external software. Recording captures exactly what's being rendered to the output, including all effects and warp.

Starting a Recording

  1. Click the Record button in the toolbar (red circle icon)
  2. Recording begins immediately — the button pulses red to indicate active recording
  3. Click the button again to stop recording
  4. The video file is saved to your configured output folder

Recording Settings

SettingOptionsDescription
FormatWebM, MP4Video container format. WebM is faster to encode; MP4 is more universally compatible
Output FolderCustom pathWhere recordings are saved. Auto-generated filenames with timestamp
ResolutionCanvas sizeRecords at the current canvas resolution
Tip

Use WebM for quick captures during development. Switch to MP4 for final recordings that need to work in video editors and social media.

Spout Output

Spout is a real-time video sharing framework that lets applications share GPU textures without performance overhead. Shrink Wrap can output its rendered visuals via Spout to other software running on the same machine.

Common Uses

  • OBS Studio — Capture Shrink Wrap output for live streaming
  • Resolume / TouchDesigner — Feed Shrink Wrap into larger VJ rigs
  • Unity / Unreal — Use Shrink Wrap as a texture source in game engines
  • LED controllers — Route video to LED wall controllers

Enabling Spout

  1. Open Output Settings in the toolbar
  2. Toggle Spout Output on
  3. A sender name appears (configurable)
  4. In the receiving application, select the Shrink Wrap Spout sender
Note

Spout is currently available on Windows only. macOS users can use Syphon-based workflows with similar results.

Display Management

Shrink Wrap can output to any connected display or projector. Configure which display receives the visual output:

Display Selection

  • Primary display — Your main monitor (windowed or fullscreen)
  • Secondary display — A connected projector or external monitor
  • Span — Output across multiple displays for multi-projector setups

Fullscreen Mode

Press F11 to toggle fullscreen output. In fullscreen, the entire display is used for visual output with no UI chrome. Press F11 again or Esc to return to windowed mode.

4K Output

Shrink Wrap renders at up to 4K resolution (3840 x 2160) at 60fps. For best 4K performance:

FactorRecommendation
GPUModern dedicated GPU (RTX 3060+ or equivalent AMD)
VRAM6 GB+ for comfortable 4K with multiple layers
ConnectionHDMI 2.0+ or DisplayPort 1.4+ for 4K60
Layer CountReduce active layers or effects if framerate drops

Performance Optimization

Tips for maintaining smooth performance:

  • Reduce layer count — Each active layer consumes GPU resources. Disable layers you're not using.
  • Simplify effect chains — Complex multi-effect chains are the biggest performance cost. Remove effects you don't need.
  • Lower resolution for development — Work at 1080p during setup, switch to 4K only for final output.
  • Watch the FPS counter — The toolbar shows real-time FPS. If it drops below 30, simplify your composition.
  • Pre-render heavy content — For 3D models and gaussian splats, let them load fully before starting performance.
  • Close other applications — GPU-intensive apps (browsers with many tabs, games, video editors) compete for resources.
  • Update GPU drivers — Latest drivers often include performance improvements for WebGL.
Tip

For the smoothest live performances, always run a full rehearsal at your venue to identify any performance bottlenecks before the show.
