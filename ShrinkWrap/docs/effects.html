Effects Pipeline

Every layer in Shrink Wrap can have a chain of real-time post-processing effects. This reference covers all 81+ built-in effects across 16 categories and 26 blend modes.

How Effects Work

Each layer can have its own chain of post-processing effects. Effects are processed sequentially — the output of one effect feeds into the next, creating a pipeline from the raw layer content to the final composited result.

  • Add an effect — Click the + button at the bottom of the effects list in the properties panel to add a new effect to the chain.
  • Remove an effect — Click the X button on an effect header to remove it from the chain.
  • Reorder effects — Drag and drop effects to change their order in the chain. Order matters: a blur before a color shift produces a different result than the reverse.

Common Effect Controls

Every effect shares a set of common controls:

ControlDescription
EnabledToggle the effect on or off without removing it from the chain
OpacityBlend the effect result with the original input (0 = no effect, 1 = full effect)
Blend ModeHow the effect output composites with the original layer content
ParametersType-specific controls unique to each effect (sliders, color pickers, dropdowns)
Tip

Use the enabled toggle to quickly A/B compare the effect. Lower the opacity to subtly blend an effect rather than applying it at full strength.

Blend Modes

Both layers and individual effects support 26 blend modes. The blend mode controls how the layer or effect output composites with the content beneath it.

Blend ModeDescription
NormalStandard alpha-based compositing
MultiplyDarkens by multiplying color values; white is transparent
ScreenBrightens by inverting, multiplying, and inverting; black is transparent
DifferenceAbsolute difference between layers; identical pixels become black
AddLinear dodge; adds color values for a brightening effect
SubtractSubtracts top layer from bottom; darkens the result
OverlayCombines Multiply and Screen based on base luminance
DarkenKeeps the darker pixel from each layer
LightenKeeps the lighter pixel from each layer
ExclusionSimilar to Difference but lower contrast
Hard LightMultiply or Screen depending on blend layer brightness
Soft LightSubtle dodge/burn effect; softer than Overlay
Color DodgeBrightens base by decreasing contrast toward blend color
Color BurnDarkens base by increasing contrast toward blend color
HueApplies hue of blend layer with saturation and luminosity of base
SaturationApplies saturation of blend layer with hue and luminosity of base
ColorApplies hue and saturation of blend layer with luminosity of base
LuminosityApplies luminosity of blend layer with hue and saturation of base
DivideDivides base by blend; useful for removing color casts
AverageSimple average of both layers
NegationInverted absolute difference; inverts similar colors
PhoenixMin plus max minus one; creates warm ethereal blending
Linear LightLinear Burn or Linear Dodge based on blend brightness
Hard MixPosterizes result to pure channel values for high-contrast graphic looks
Vivid LightColor Burn or Color Dodge based on blend brightness
Pin LightReplaces pixels based on blend brightness thresholds
Tip

Screen and Add are ideal for layering light effects over dark backgrounds. Multiply works well for projecting textures onto surfaces. Difference is useful for creating abstract motion-reactive visuals.
