MIDI & Audio

Map MIDI controllers to any parameter and drive visuals from audio input. Beat detection, frequency analysis, and LFO modulation for music-reactive performance.

MIDI Overview

Shrink Wrap supports MIDI input from any connected controller. Map knobs, faders, buttons, and pads to control visual parameters in real-time. Multiple MIDI devices can be connected simultaneously.

Controller Setup

  1. Connect your MIDI controller via USB (or MIDI interface)
  2. Shrink Wrap automatically detects available MIDI devices
  3. Open the MIDI Settings panel from the toolbar
  4. Your controller should appear in the device list
  5. Enable the device to start receiving MIDI messages
Tip

Connect your MIDI controller before launching Shrink Wrap for the most reliable detection. If you connect a device after launch, use the refresh button in MIDI Settings.

Learn Mode

The fastest way to map MIDI controls to parameters is Learn Mode:

  1. Click the MIDI Learn button (or the small MIDI icon next to any parameter)
  2. The parameter enters learn mode and waits for a MIDI message
  3. Move a knob, fader, or press a button on your MIDI controller
  4. The mapping is created automatically — the MIDI control now drives that parameter

Editing Mappings

After creating a mapping, you can fine-tune it:

SettingDescription
Input RangeMap a subset of the MIDI range to the parameter range
Output RangeLimit the parameter's travel range
InvertReverse the mapping direction
SmoothingAdd smoothing to reduce jitter from noisy controllers

Removing Mappings

Right-click a mapped parameter and select Remove MIDI Mapping, or use the MIDI Settings panel to manage all mappings.

Message Types

Shrink Wrap supports three types of MIDI messages:

TypeRangeBest For
CC (Control Change)0 - 127Knobs, faders, continuous controls
Note On/Off0 - 127 (velocity)Buttons, pads, toggle controls
Pitch Bend0 - 16383Pitch wheels, high-resolution continuous control

CC Messages

The most common mapping type. Each CC number (0-127) on each channel is an independent control. Most MIDI knobs and faders send CC messages. The 7-bit resolution gives 128 steps of control.

Note Messages

Note On/Off messages work well for toggle parameters (on/off switches) and trigger actions (clip launching). The velocity value (0-127) can optionally drive the parameter value.

Pitch Bend

Pitch bend provides 14-bit resolution (16,384 steps) for ultra-smooth continuous control. Ideal for parameters that need fine adjustment like position or smooth fades.

Channel Filtering

MIDI messages are sent on channels 1-16. You can filter by channel to avoid conflicts when multiple controllers or instruments share a MIDI connection.

  • All Channels — Accept messages from any channel (default)
  • Specific Channel — Only respond to messages on the selected channel (1-16)

This is especially useful in live setups where a DJ controller, drum pad, and keyboard might all be connected via the same MIDI interface.

Audio Reactivity

Shrink Wrap can analyze incoming audio in real-time and use it to drive visual parameters. This creates visuals that pulse, shift, and respond to music automatically.

Audio Input Setup

  1. Open Audio Settings from the toolbar
  2. Select your audio input device (microphone, line-in, or virtual audio cable)
  3. The audio level meter shows that audio is being received
  4. Enable audio reactivity on individual layer parameters
Tip

For best results, use a direct audio feed (line-in or virtual audio cable from your DJ software) rather than a microphone, which picks up room noise and crowd sounds.

Frequency Bands

Audio input is analyzed across 6 frequency bands. Each band can independently drive different parameters for rich, frequency-specific visual responses.

BandFrequency RangeTypical Content
Sub20 - 60 HzSub-bass rumble, deep kicks
Bass60 - 250 HzKick drums, bass guitar, bass synths
Low Mid250 - 500 HzWarm body of instruments
Mid500 Hz - 2 kHzVocals, lead instruments, snare body
High Mid2 - 6 kHzVocal presence, guitar attack, snare snap
High6 - 20 kHzCymbals, hi-hats, air, sibilance

Additionally, an All band option combines all frequencies into a single response value, useful for overall volume-reactive effects.

Audio Parameters

ParameterRangeDescription
Sensitivity0 - 3Amplify the audio signal for stronger visual response
Smoothing0 - 1Smooth out rapid changes for flowing visuals (higher = smoother)
Threshold0 - 1Minimum audio level before reactivity kicks in

Beat Detection

Shrink Wrap includes automatic beat detection that identifies rhythmic patterns in the audio input. Detected beats can trigger visual events like:

  • Scale punch — Layers scale up on each beat then return
  • Color flash — Brief color shift on beat hits
  • Rotation kick — Rotation impulse synced to beats
  • Effect intensity — Boost effect parameters on beats

Beat detection works best with music that has a clear rhythmic pulse. Electronic dance music, hip-hop, and pop typically give the strongest detection.

LFO Modulation

Low Frequency Oscillators (LFOs) generate repeating wave patterns that can modulate any parameter. Unlike audio reactivity which responds to external input, LFOs create their own rhythmic modulation.

LFO Waveforms

  • Sine — Smooth, organic modulation
  • Triangle — Linear ramp up and down
  • Square — Hard on/off switching
  • Sawtooth — Ramp up, then snap back

LFO Parameters

ParameterDescription
RateSpeed of oscillation (Hz or beat-synced)
DepthHow much the LFO affects the target parameter (0-1)
PhaseStarting position in the waveform cycle
Sync to BPMLock LFO rate to the global BPM for tempo-synced modulation
Tip

Combine audio reactivity on one parameter (like brightness from bass) with an LFO on another (like hue cycling) for complex, layered visual behavior that feels both musical and evolving.
