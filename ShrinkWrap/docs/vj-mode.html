VJ Mode

A professional clip launcher for live visual performance. Trigger clips, manage compositions, and automate layer sequences in real-time.

Overview

VJ Mode transforms Shrink Wrap from a composition tool into a live performance instrument. Switch to VJ Mode by pressing Tab or clicking the VJ Mode button in the toolbar.

In VJ Mode, you get a 16-channel clip launcher grid (4 layers x 8 columns), composition management, stage presets for instant scene switching, and a beat-synced layer sequencer.

Clip Launcher

The clip launcher is a grid of triggerable visual clips, organized into 4 layer rows with 8 clip slots each. Each row corresponds to a layer in your composition — triggering a clip in a row replaces the active visual on that layer.

Grid Layout

PropertyValue
Rows4 (one per layer)
Columns8 (clip slots per layer)
Total Clips32 per composition

Each clip slot can hold any type of layer content: a shader, media file, 3D model, or any other layer type. The clip retains all parameter settings, effects, and warp configurations.

Loading Clips

To load content into a clip slot:

  1. Right-click on an empty clip slot in the grid
  2. Select the layer type you want to load (ISF Shader, Media, 3D Model, etc.)
  3. Configure the content using the properties panel that appears
  4. The clip thumbnail updates to show a preview of the content

You can also drag content from your mapping layers directly into VJ clip slots. This copies the entire layer configuration including all effects and settings.

Tip

Pre-load all your clips before a performance. Each clip stores its full configuration, so switching between clips is instantaneous with no loading delay.

Triggering & Crossfading

Click any clip in the grid to trigger it. The clip immediately starts rendering on its layer row. The previously active clip on that row is replaced.

Crossfade

Clips can crossfade between each other for smooth transitions. The crossfade duration is configurable per layer and applies whenever you switch clips on that row.

Empty Slots

Clicking an empty slot or the currently active clip will clear that layer, making it transparent.

Compositions

A composition is a saved state of the entire clip launcher grid. It remembers which clips are loaded in all 32 slots and which clips are currently active.

Saving a Composition

  1. Set up your clip grid with all the content you need
  2. Click Save Composition in the VJ panel
  3. Name your composition
  4. The composition is stored in your project file

Loading a Composition

Select a composition from the dropdown to load it. All 32 clip slots are restored to their saved state. The currently active clips begin rendering immediately.

Stage Presets

Stage presets go beyond compositions — they save and recall the complete state of all mapping layers, including every parameter, effect chain, warp configuration, and blend mode.

Creating a Stage Preset

  1. Configure your entire visual setup across all layers
  2. Open the Stage Presets panel
  3. Click Save Preset and give it a name
  4. The preset captures the full state of every layer

Recalling a Stage Preset

Click any saved preset to instantly switch your entire visual output. This is perfect for scene changes during a live show — one click changes everything.

Tip

Create stage presets for each section of your show (intro, verse, chorus, breakdown, finale). During performance, you can switch entire visual environments with a single click or MIDI trigger.

Layer Sequencer

The layer sequencer automates layer visibility and transitions over time, synced to your BPM. Use it to create evolving visual sequences that run automatically during a performance.

Timeline

Each layer gets a timeline track showing when it's visible (active) and when it's hidden. Click on the timeline to toggle visibility at specific beat positions.

Quantization

All sequencer actions snap to the current beat grid. This ensures your visual changes are perfectly synchronized with the music. Supported quantization values include whole notes, half notes, quarter notes, and eighth notes.

Loop

The sequencer loops at a configurable length (default: 8 bars). When the playhead reaches the end, it wraps back to the beginning for continuous automated performance.

BPM & Timing

Set the global BPM (beats per minute) to synchronize the sequencer and any tempo-synced effects with your music.

ParameterRangeDescription
BPM20 - 300Beats per minute for sequencer and tempo-synced effects
Time Signature2/4, 3/4, 4/4, 6/8Beat grouping for the sequencer grid
Tap Tempo—Tap a button in time with the music to set BPM
Tip

Use tap tempo to match BPM with a live DJ or band. Tap along with the beat for 4-8 beats and the BPM will be calculated automatically.
