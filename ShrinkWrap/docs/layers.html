Layer Types

Shrink Wrap provides 9 distinct layer types, each tailored for a specific kind of visual content. Every layer type can be composited with blend modes, opacity, and the full effects pipeline.

ISF Shader Engine

GPU-accelerated GLSL fragment shaders using the ISF (Interactive Shader Format) standard. ISF shaders run entirely on the GPU, producing generative visuals at full frame rate with zero CPU overhead.

Built-in Shader Library

Shrink Wrap ships with 100+ built-in shaders spanning a wide range of visual styles: fractals, particle systems, kaleidoscopes, voronoi patterns, plasma fields, sacred geometry, reaction-diffusion, and more. Browse and preview shaders in the Shader Browser that appears in the properties panel when an ISF layer is selected.

ThreeBody Mega-Shader

The ThreeBody shader is a consolidated mega-shader offering 30 orbital presets (based on periodic three-body solutions from the Suvakov-Dmitrasinovic and Li-Liao catalogs) combined with 12 effect styles and a quality selector. This single shader produces hundreds of unique visual combinations.

Real-Time Parameter Controls

Each ISF shader declares its own set of parameters, and Shrink Wrap automatically generates the appropriate UI control for each type:

Custom Shader Loading

Load your own ISF-format shaders by importing .fs files. Custom shaders are parsed for their parameter declarations and receive the same auto-generated UI controls as built-in shaders.

Tip

ISF is an open standard. You can find hundreds of community shaders at isf.video that are compatible with Shrink Wrap.

Media Layer

Load and play back image and video files directly as layers. Media layers support a wide range of formats and come with playback, trimming, and fit controls.

Supported Formats

  • Video — MP4, MOV, WebM
  • Image — PNG, JPG, GIF

Playback Controls

ParameterRangeDescription
Play / Pause—Start or stop video playback
Loop Modeloop, once, timelapseContinuous looping, play once, or timelapse mode
Playback SpeedMultiplierSpeed up or slow down playback
Trim Start0–1Normalized start point for playback
Trim End0–1Normalized end point for playback

Timelapse Mode

When loop mode is set to timelapse, the video advances by one frame at a configurable interval (1–30 seconds between frames). This is useful for creating slow, contemplative visual sequences from video footage.

Content Fit

Choose how media fills the layer bounds:

  • Stretch — Scale to fill, may distort aspect ratio
  • Fill — Scale to fill, crop overflow to maintain aspect ratio
  • Crop — Display at original size, crop to layer bounds

Chromakey

Remove a color from the media layer (green screen, blue screen, etc.) with adjustable threshold (0–1) and softness (0–1) controls for clean edge blending.

Tip

All 81+ effects from the effects pipeline can be chained onto media layers, turning simple video loops into complex animated compositions.

Embedded File Animations

GLTF and FBX files can contain embedded skeletal or keyframe animations. When detected, Shrink Wrap enables the Use File Animation toggle and a File Animation Speed control. These play back the animation data baked into the 3D file, such as walk cycles, character poses, or mechanical movements.

Lines

Draw lines directly on the canvas with a full set of stroke styles, drawing animations, and warp controls. Lines are ideal for PVC pipe mapping on stage structures, neon outlines, architectural tracing, and animated motion graphics.

Drawing Tools

  • Freehand — Draw continuous strokes with smoothing (0–1) and pressure sensitivity support
  • Point-Click — Place individual points to create polylines. Options for closed shapes and corner styles: sharp, rounded, or chamfer

Color Layer

The simplest layer type: a solid color fill. Despite its simplicity, the color layer is a versatile tool for backgrounds, tinting, and blend mode overlays.

HSL Controls

ParameterRangeDescription
Hue0–360Color hue on the color wheel
Saturation0–100Color intensity (0 = gray, 100 = vivid)
Lightness0–100Brightness (0 = black, 50 = pure color, 100 = white)
Alpha0–1Layer transparency

Common Use Cases

  • Background tints — Place a color layer at the bottom of the stack as a solid background
  • Color washes — Layer a semi-transparent color over other layers with a blend mode like Overlay or Soft Light
  • Blend mode overlays — Use Add, Multiply, or Screen blend modes with a color layer to tint or adjust the overall composition
Tip

Apply the effects chain to a color layer to create animated color effects. For example, chain a noise effect and color ramp to turn a simple color into a dynamic gradient background.
