Projection Mapping

Precision tools for mapping visuals onto any surface. Corner warping, mesh grids, per-element transforms, and multi-projector edge blending.

Overview

Projection mapping is the process of aligning your visual output to match physical surfaces. Shrink Wrap provides multiple warp modes that can be used independently or combined:

  • Corner warp — 4-point pin for quick alignment to flat surfaces
  • Mesh warp — Grid-based warping for curved or complex surfaces
  • Per-element warp — Individual transform on shapes/lines within drawing layers
  • Layer shape masks — Clip layers to geometric shapes

Corner Warping

The most common mapping technique. Each layer has 4 corner control points that can be dragged to match a surface.

How to Use

  1. Select the layer you want to map
  2. Set warp mode to Corners in the layer properties
  3. Drag the 4 corner handles on the canvas to align with your projection surface
  4. Fine-tune by entering exact coordinate values in the properties panel

Corner Coordinates

Each corner is defined by an X/Y position normalized to 0-1 (where 0,0 is top-left and 1,1 is bottom-right of the output). The default corners are the four edges of the canvas.

CornerDefault XDefault Y
Top Left0.00.0
Top Right1.00.0
Bottom Left0.01.0
Bottom Right1.01.0
Tip

Use mobile control to adjust warp points while standing at the projection surface. This lets you see exactly how the content aligns from the audience perspective.

Mesh Warping

For curved surfaces or complex shapes, mesh warping uses a grid of control points that can be individually adjusted.

Grid Configuration

ParameterRangeDescription
Rows2 - 20Number of horizontal grid divisions
Columns2 - 20Number of vertical grid divisions

Editing Mesh Points

  1. Set warp mode to Mesh
  2. Adjust grid density (more points = finer control, but harder to manage)
  3. Drag individual grid intersection points to warp the content
  4. The content deforms smoothly between control points using bilinear interpolation
Tip

Start with a coarse grid (3x3 or 4x4) and increase density only where you need finer control. Too many control points makes adjustment tedious.

Per-Element Warp

Lines and drawing layers support warping individual elements independently. Each line or shape can have its own corner warp and mesh warp applied.

Element Corner Warp

Select an element in a Lines layer and enable corner warp. The element gets its own 4-corner pin that transforms just that element within the layer.

Element Mesh Warp

For more complex per-element shaping, enable mesh warp on an individual element. This is useful for mapping individual lines to curved PVC pipes or architectural features.

Layer Shape Masks

Layer shapes act as clip masks that constrain the layer's visible area to a geometric shape. This is useful for projecting onto specific surface geometries.

Available shape masks include circles, triangles, rectangles, polygons, and custom point-based shapes. The shape can be transformed independently of the layer content.

Multi-Projector Setup

For large installations, Shrink Wrap supports output to multiple displays and projectors. Each layer can be mapped independently, allowing different content on different projectors from a single project.

Setup Steps

  1. Connect multiple displays/projectors to your computer
  2. Extend your desktop across all displays (not mirrored)
  3. In Shrink Wrap, configure the output window to span your projector displays
  4. Use corner/mesh warp on each layer to align content to the physical surface covered by each projector

Edge Blending

When multiple projectors overlap, edge blending creates smooth transitions in the overlap zone. The edge feather effect can be used to gradually fade the edges of each projector's output so the overlap appears seamless.

Using Edge Feather for Blending

Apply the Edge Feather effect to layers that need blending. Adjust the feather width on the edge where projectors overlap. Both projectors should feather the same edge for a smooth blend.

Top0 - 0.5Feather width from top edge

Mapping Workflow

A typical projection mapping workflow:

  1. Physical setup — Position your projector(s) to cover the target surface
  2. Alignment layer — Create a simple grid or solid color layer and use corner warp to roughly align to the surface
  3. Fine-tune with mesh — Switch to mesh warp for areas that need curved or non-linear mapping
  4. Content layers — Add your visual content layers and apply the same warp configuration
  5. Walk the venue — Use mobile control to fine-tune alignment from the audience's perspective
  6. Save the preset — Save your warp configuration as a stage preset so you can recall it at the venue
Tip

Always do your final alignment with the actual content playing, not just a test pattern. Some content looks different at the edges and may need slight adjustments from what a grid pattern would suggest.
