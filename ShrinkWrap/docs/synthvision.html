SynthVision Performer

A 36-key visual instrument for triggering and performing visuals live. Map any content to keyboard keys, create presets, and perform in full-screen mode.

Overview

SynthVision turns your keyboard into a visual performance instrument. Each key can trigger a different visual — a shader, video clip, 3D model, or any other layer type. Press keys to switch visuals instantly, creating dynamic live performances.

Keyboard Layout

SynthVision provides 36 assignable key slots arranged in 4 rows, mirroring a standard keyboard layout:

RowKeysCount
Row 1 (top)1 2 3 4 5 6 7 8 9 010
Row 2Q W E R T Y U I O P10
Row 3A S D F G H J K L9
Row 4 (bottom)Z X C V B N M7

Each key slot shows a thumbnail preview of its assigned content. Empty slots appear as outlined boxes waiting for assignment.

Assigning Content

To assign visual content to a key:

  1. Enter Edit Mode (toggle with the edit button)
  2. Click on the key slot you want to assign
  3. Select the content type and configure it using the properties panel
  4. The key slot updates with a thumbnail preview

Content Types

Any layer type can be assigned to a key: ISF shaders, media files, 3D models, gaussian splats, lines, light paintings, SVG graphics, animated text, or solid colors.

Clearing Assignments

In edit mode, right-click a key to clear its assignment. The slot returns to empty.

Edit Mode

Edit mode is where you set up your keyboard layout. In this mode:

  • Click keys to assign or modify content
  • Right-click keys to clear assignments
  • The RESET button appears — click to clear all assignments
  • Access preset management (save/load/delete)
  • Drag and drop to rearrange key assignments

Perform Mode

Exit edit mode to enter perform mode. Now the keyboard becomes your instrument:

  • Press any assigned key to trigger that visual instantly
  • The active visual renders to your output display/projector
  • Press a different key to switch visuals
  • The active key is highlighted in the interface

Full-Screen Performance

For live shows, enter full-screen mode to maximize your canvas output. The SynthVision keyboard overlay can be toggled on/off so you can see which keys are available while performing.

Keyboard Presets

Save your entire keyboard layout as a preset to recall later. This is perfect for preparing different sets for different shows or songs.

Saving a Preset

  1. Set up all your key assignments in edit mode
  2. Click Save Preset
  3. Name your preset
  4. The preset stores all 36 key assignments and their configurations

Loading a Preset

Select a saved preset from the dropdown to restore all key assignments. Your previous assignments are replaced.

Storage

Presets are saved in your browser's local storage. They persist across sessions but are tied to the specific browser and machine.

Tip

Create different presets for different segments of your show. Load the "intro" preset for your opening set, then switch to "main" or "finale" presets mid-performance.

Performance Tips

  • Organize by position — Put related visuals near each other on the keyboard. Use the number row for backgrounds, QWERTY for main content, ASDF for accents.
  • Practice your layout — Know where each visual lives so you can trigger without looking.
  • Combine with MIDI — Map MIDI controller buttons to keyboard keys for hardware triggering. See MIDI & Audio.
  • Pre-render heavy content — If using 3D models or complex shaders, make sure they're loaded and warmed up before performing.
