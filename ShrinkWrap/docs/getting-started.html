Getting Started

Install Shrink Wrap, learn the interface, and create your first visual project in minutes.

Installation

macOS

  1. Download the .dmg file from the download page
  2. Open the DMG and drag Shrink Wrap to your Applications folder
  3. On first launch, right-click the app and select Open to bypass Gatekeeper
  4. The app will start and display the main workspace

Windows

  1. Download the .msi installer from the download page
  2. Run the installer and follow the prompts
  3. Launch Shrink Wrap from your Start menu or desktop shortcut

Interface Overview

The Shrink Wrap interface is designed around a central canvas with panels on each side:

Main Canvas

The center of the screen shows your live visual output. This is what gets sent to your projector or display. You can interact directly with the canvas to move, warp, and edit layer content.

Layer Panel (Left)

Lists all layers in your project from top to bottom. Each layer has visibility, lock, and solo toggles. Click a layer to select it and show its properties. Drag layers to reorder them in the composition stack.

Properties Panel (Right)

Shows controls for the currently selected layer. The available controls change based on the layer type. This is where you adjust shader parameters, media playback, 3D model properties, effects chains, and more.

Toolbar (Top)

Quick access to project management (new, save, load), display settings, recording controls, and mode switching (mapping mode vs VJ mode).

Add Layer Menu

Click the + button at the bottom of the layer panel to add a new layer. Choose from 9 layer types: ISF Shader, Media, 3D Model, Gaussian Splat, Lines, Light Painting, SVG, Text, or Color.

Your First Project

  1. Add a shader layer — Click + in the layer panel, choose ISF Shader. A shader browser appears in the properties panel. Click any shader to load it. You'll see it rendering live on the canvas.
  2. Adjust parameters — Each shader exposes real-time controls (sliders, color pickers, dropdowns). Experiment with different values to change the visual output.
  3. Add a second layer — Click + again and add a Media layer. Load an image or video file. It appears above the shader layer.
  4. Blend layers — With the media layer selected, change its blend mode from Normal to something like Screen or Add. Adjust opacity to mix the two layers together.
  5. Save your work — Use Ctrl+S (or Cmd+S on Mac) to save your project as a .ghost-arcade file.

Basic Compositing

Layer Order

Layers render from bottom to top. The topmost layer in the panel is drawn last (on top of everything). Drag layers to reorder them.

Blend Modes

Each layer has a blend mode that controls how it combines with the layers below it. Common choices:

  • Normal — Standard opacity-based layering
  • Add — Brightens (great for light effects)
  • Multiply — Darkens (great for shadows and textures)
  • Screen — Like Add but softer
  • Overlay — Combines Multiply and Screen for contrast

Shrink Wrap offers 25+ blend modes. See Blend Modes for the full list.

Opacity

The opacity slider (0-100%) controls layer transparency. At 0% the layer is invisible; at 100% it's fully opaque (subject to blend mode).

Effects Chains

Each layer can have a chain of post-processing effects applied to it. Effects are processed in order and can be reordered by dragging. See Effects Pipeline for details.

Saving & Loading Projects

Project Files

Projects are saved as .ghost-arcade files, which contain all layer configurations, effect chains, warp settings, and references to media files.

Save

Press Ctrl+S / Cmd+S or use File > Save. On first save, you'll be prompted to choose a location and filename.

Load

Press Ctrl+O / Cmd+O or use File > Open. Select a .ghost-arcade file to load.

New Project

Use File > New to start a fresh project. You'll be asked to confirm if you have unsaved changes.

Tip

Keep your media files (videos, images, 3D models) in a folder alongside your .ghost-arcade file. The project stores relative paths, so moving the project folder keeps everything connected.
